## Deskripsi

Repository ini berisi kumpulan contoh program mata kuliah Pemrograman Berorientasi Objek menggunakan bahasa pemrograman Java.

Materi disediakan sebagai bahan pembelajaran, live coding, latihan, dan praktikum mahasiswa.

## Software yang Digunakan

- Java Development Kit (JDK)
- Apache NetBeans IDE

## Cara Menggunakan Project

1. Klik tombol Code pada repository ini.
2. Pilih Download ZIP.
3. Ekstrak file ZIP.
4. Buka aplikasi Apache NetBeans.
5. Pilih File → Open Project.
6. Pilih folder project yang telah diekstrak.
7. Buka package sesuai materi perkuliahan.
8. Klik kanan pada class yang memiliki method main, kemudian pilih Run File.
